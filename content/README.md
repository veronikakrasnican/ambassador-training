# Module content

Put the seven module files here, named exactly:

module-1.md, module-2.md, module-3.md, module-4.md, module-5.md, module-6.md, module-7.md

How to create them:
1. Open the curriculum Claude Doc and go to the "Module 1 content" tab.
2. Export or download the tab as Markdown (.md).
3. Rename the file to module-1.md and upload it to this folder on GitHub.
4. Repeat for Modules 2 to 7.

To change the training later, edit the Doc, export the tab again and replace the file.
The app reads the units, case files, decisions, debriefs, "Your turn" tasks, takeaways and
reflections straight from these files. "Notes" sections are ignored, so they never reach ambassadors.
